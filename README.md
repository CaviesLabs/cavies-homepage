# Cavies Studio website

The cavies.xyz website lives in [`studio/`](studio/README.md): a Next.js app deployed by the Vercel project `cavies/cavies-studio` with Root Directory `studio` and production branch `main`. The Studio README covers development, validation, content, and deployment.

The original Cavies Labs website that used to live at the repository root was removed in October 2026. Its last complete state is tagged [`legacy-cavies-labs-site`](https://github.com/CaviesLabs/cavies-homepage/tree/legacy-cavies-labs-site).
